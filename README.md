# Handy Holmz AI Estimator

Conversational project estimating for an independent handyman serving Park Ridge, Illinois.

## Planned features
- AI chat workspace with live estimate panel
- Hybrid fixed-price and hourly line items
- Labor, materials, overhead, and margin calculations
- Sourced local market rate comparisons
- Operator-approved customer quotes

Initial development repository. No live AI or market-rate integration yet.
